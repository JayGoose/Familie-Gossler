# Datenschutztext – Vorlage

Der Digitale Stammbaum der Familie Gossler ist ein privates Familienprojekt.

## Zugang
Ohne gültigen Zugang werden keine Familiendaten angezeigt. Ein zeitlich begrenzter
Familientag-Gastzugang ermöglicht ausschließlich lesenden Zugriff auf ausgewählte
genealogische Informationen. Kontaktdaten werden Gästen nicht angezeigt.

## Verarbeitete Daten
Je nach vorhandener Quelle können Name, Geburtsname, Lebensdaten, Verwandtschaft,
Beruf, Wohnort, Vita, Foto und – nur für freigegebene Mitglieder – Kontaktdaten
gespeichert werden.

## Zweck
Die Daten dienen ausschließlich der privaten Familienchronik und genealogischen
Dokumentation.

## Rechte
Betroffene Familienmitglieder können Berichtigung, Einschränkung oder Entfernung
eigener Angaben verlangen. Administrator-Kontakt: in `runtime-config.js` hinterlegen.

## Fotos
Fotos lebender Personen sollen nur mit deren Einverständnis eingestellt werden.

## Hosting
Die Anwendung verwendet GitHub Pages für das Frontend und Supabase für
Authentifizierung, Datenbank und geschützte Dateien.
